1. Install and start

One command installs Specyard. Run specyard in a repo: it checks the workflow skills and Claude Code, finds specs/<project>/, starts the local UI and opens it. It keeps watching specs/ for changes. It needs no config.

US1, US2, US3, US9
$ npm install -g specyard added 1 package in 3s ~/workplace/ledger $ specyard specyard 0.1.0 ✓ Claude Code 2.1.314, logged in ✓ skills in ~/.claude/skills to-brd to-design to-milestones to-tasks implement-feature verify expert-review pr ! verify is older than the version Specyard expects (no Rerun section). Update: specyard skills update Skip: specyard --no-skill-check ✓ specs/ledger/ requirements.md design.md milestones.md 3 milestones, 8 features, 31 tasks ! 1 stale: m3-statements/f1-monthly-statement/tasks.md is older than design.md → UI at http://localhost:4317 (opened in your browser) Watching specs/ for changes. Runs continue if you close the browser. Ctrl-C stops the UI and asks about running runs.

Other commands

specyard skills installInstall or update the workflow skills in ~/.claude/skills (for an Adopter who does not have them).
specyard --path specs/ledgerUse this spec folder when the repo has more than one project.
specyard runsList running and recent runs in the terminal.
